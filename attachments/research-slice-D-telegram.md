# High-Confidence Language Findings

## Syntax

### F01 — Default Telegram teaching sentence is short, verb-late or verbless
- **Observation:** `تفاوت توزیع t و نرمال چیه؟` / `عامل اصلی خطای نوع دوم`. Papers would write `تفاوت توزیع t با توزیع نرمال در این است که…`.
- **Evidence:** T03, T04, T27.
- **Register:** spoken-explanatory.
- **Exceptions:** T01 writes full academic sentences.
- **Confidence:** high

### F02 — Question syntax uses `چیه` / `چطور` / `چطوری` / `چیا هستن`
- **Observation:** Spoken copula and plural `چیا`. Academic pages use `چیست` / `کدام‌اند` only in FAQ if matching student search, never in a fake abstract.
- **Evidence:** T03, T04, T15.
- **Register:** student-facing Telegram.
- **Exceptions:** T02/T31 more formal `آیا`.
- **Confidence:** high

### F03 — Second person is the unmarked Telegram address
- **Observation:** `پایان‌نامه‌ات رو خودت بنویسی`, `گوش کنین`, `عضو کانال باش`. Papers: impersonal. SKILL leak #1 is `تو` in body copy.
- **Evidence:** T04, T05, T03, T08.
- **Register:** Telegram vs academic.
- **Exceptions:** T01 often impersonal; T10 uses `دانشجویان… لازم است`.
- **Confidence:** high

### F04 — Inclusive `مون` / `یم` marks in-group teaching
- **Observation:** `پروپوزال‌مون`, `رشتمون`, `یاد می‌گیریم`. Softens hierarchy. Do not put in چکیده.
- **Evidence:** T04, T05, T03.
- **Register:** spoken-explanatory.
- **Exceptions:** association channels (T07, T12) avoid it.
- **Confidence:** high

### F05 — Faculty hashtags freeze noun-phrase syntax; tutor hashtags freeze questions
- **Observation:** Two heading grammars on one platform.
- **Evidence:** T02 vs T04.
- **Register:** academic-pedagogical vs spoken.
- **Exceptions:** mixed posts inside one channel.
- **Confidence:** high

# Register Map

Telegram is not one register. For the SKILL:

1. **Named faculty explanatory** (T01) → closest to professional web article; strip emoji.
2. **Faculty syllabus tags** (T02) → source of heading nouns.
3. **Tutor spoken** (T03, T04) → source of reader questions; not body style.
4. **Empowerment education** (T05) → FAQ warmth without ghostwriting.
5. **Professional association** (T07, T12) → event and term-coining, not methods teaching.
6. **Library bureaucratic** (T10) → facts (Irandoc steps) in human verbs.
7. **Campus news** (T11) → plain official.
8. **Commercial stats** (T08, T21) → negative example.
9. **Exam-prep methods** (T13) → denser technical lexicon, still `شما`.

# Syntax and Rhythm Rules

1. Convert `#سوال: چطور X؟` → heading `X` or FAQ `X چگونه نوشته می‌شود؟`
2. Convert second person to impersonal in body; allow `شما` in FAQ.
3. Expand telegraphic notes into SOV sentences with the verb last.
4. One channel ≠ one style; classify the post.
5. Deduplicate mirrors (Bale/Eitaa/Instagram/site).
6. Never structure a page with emoji as bullets of record.

# Anti-AI / Translationese Findings

Telegram itself is a source of AI-like web prose: hype, CTA, secret-lists, mixed English-move names, fused registers. The SKILL should treat high-engagement tutor copy as **reader-language evidence** and **negative style evidence**, except T01-like hedges.

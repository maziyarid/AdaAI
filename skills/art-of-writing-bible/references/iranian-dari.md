# Iranian Persian vs Afghan Dari

Mandatory. Applies to every artefact: landing, FAQ, thesis, clinic, Telegram-derived FAQ, English-to-Persian translation, UX microcopy.

The reader of Maziyar's sites and agents is an **Iranian** reader of فارسی. Mixing دری افغانستان into the same page is not “richer Persian”. It is a register/dialect error that makes the work feel foreign and stops reading.

This is a **language** rule, not a Teznevise rule.

## Think in Iranian Persian

Do not plan the argument in English and then translate. Rebuild:

1. What is the reader trying to do, in Iranian words?
2. What is the next mental state?
3. Persian information order: known/scope → new → verb.
4. If the draft still smells like English clause architecture, throw away the wording and write the point again.

Afghan official and journalistic Dari often keeps more منشیانه copulas (`میباشم`) in running prose. Iranian web and editorial Persian prefers `است` / `هست` / `می شود`.

## Hard lexical splits (do not mix)

| Do not use (Dari / Afghan official) | Use (Iranian) |
|---|---|
| پوهنتون | دانشگاه |
| شفاخانه | بیمارستان / درمانگاه / کلینیک as the real place |
| محصل as default for university student | دانشجو |
| لیسه | دبیرستان |
| صنف for school class | کلاس |
| موتر (vehicle) | خودرو / ماشین |
| دریور | راننده |
| کمپنی / فابریکه as default | شرکت / کارخانه |
| چایخانه as default café | کافی شاپ / قهوه خانه only if that is the place |
| نمرات as only word for grades | نمره |
| numerically: Afghan texts may keep more Arabic ي/ك | Iranian ی and ک |

Do not “correct” Iranian colloquial `ماشین` into a fake-pure word on a landing page. Do not import Dari `موتر` to look formal.

## Orthography

- Iranian published Persian: `ی` `ک` (U+06CC, U+06A9).
- Arabic `ي` `ك` in Iranian body copy is a defect unless quoting Arabic.
- ZWNJ (U+200C) is standard in Iranian formal/editorial/academic Persian. Teznevise strips it at publish time — house rule.

## Morphology and copula

- Iranian web: `است`, `هست`, `می شود`, spoken writing `چیه` only in FAQ/student quote.
- Do not use `می باشم` / `نمیباشم` as default copula in Iranian pages.
- Iranian light verbs: `کردن`, `شدن`, `دادن`. Do not upgrade every verb to `نمودن` / `فرمودن` to look polite.

## What this is not

- It is not hostility to Afghan readers. If the task is explicitly Dari for an Afghan audience, write Dari and say so.
- It is not a ban on shared Persian heritage words (`کتاب`, `پژوهش`, `دانش`).
- It is a ban on **mixing** the two systems on an Iranian product surface.

## Scan before publish

Search the draft for: پوهنتون، شفاخانه، موتر، دریور، لیسه، می باشم، ي، ك.
If any hit is not a quotation, rewrite.

# Pattern bank — transferable mechanics

Evidence tags:

- **PC-STRONG** — recurs in original PhilosophyCafe writing across more than one contributor or across topics
- **COMMON** — also attested in independent Persian (slices A, D-telegram, F, or educated web prose)
- **REGISTER** — valid only in a named register
- **AUTHOR_SPECIFIC** — do not generalise; do not imitate
- **NEGATIVE** — attested as a defect, a translation, a quotation, or an AI/bureaucratic tell

Do not paste source sentences into output. Reproduce the **move**. All constructed Persian below is newly written. No U+200C.

Load this file when drafting, rewriting, or running the human editorial pass.
For academic / method / service artefacts also load `overlays.md`.

---

## 0. What this bank is for

The unit of quality is the reader's next mental state, not a pretty sentence.

Before using a pattern, answer:

1. What does the reader already think?
2. What must change in the next 8–20 seconds of reading?
3. Is this the right register for this artefact?
4. Is the claim a fact, an interpretation, or a guess?

If a pattern would make the prose more elegant and less true, discard it.

## 1. Sentence entry (how a sentence begins)

Attested functions in original contemporary Persian (PC-STRONG + COMMON):

| Function | Typical opening | Use when | Avoid when |
|---|---|---|---|
| Direct assertion | name the thing, then the verb | the reader already has the topic | the first sentence of a timid article |
| Contrast | اما / با این حال / مسئله اینجاست که | a common picture must be broken | every paragraph (becomes a tic) |
| Qualification | اگر / تا وقتی که / در این معنا | the claim is scoped | hedging an obvious fact |
| Question-pivot | پس چه؟ / یعنی چه؟ / چرا این مهم است؟ | the question changes the viewpoint | decoration / SEO hooks |
| Concrete setup | فرض کنید / نجار را در نظر بگیرید / یک دانشجو را بگیرید | abstraction is about to arrive | already-concrete how-to steps |
| Reformulation | به بیان ساده تر / یعنی / به عبارت دیگر | the previous sentence was dense | synonym-swapping the same claim |
| Return from example | حالا برگردیم / همین کار را در X هم می بینیم | an analogy has done its job | after every short clause |
| Epistemic | به نظرم / از این شواهد می توان گفت / نمی دانیم | interpretation, not fact | method reporting in a thesis |
| Distinction | نه X، بلکه Y / باید میان A و B فرق گذاشت | two things the reader is conflating | fake binary for rhythm |

PC-STRONG: sentences rarely begin with empty scene-setting (`در دنیای امروز`, `یکی از مهم ترین موضوعاتی که`). Academic abstracts (slice A) also lack those openers. Ban them.

## 2. Thirty sentence architectures

Each case describes a **construction**, then a **new** sentence on an unrelated subject (thesis / method / student work). Do not reuse source wording.

### PC-SENT-001 — familiar practice, then the false picture
- begins_with: ordinary action
- pivot: however / but the theorist asks
- ending: the practitioner cannot answer the formula, and does not need to
- register_shift: conversational → analytical
- transferable_rule: Put the lived action before the theoretical demand.
- new: «دانشجو وقتی جدول نتایج را می خواند، می فهمد کدام فرض رد شده. اگر وسط کار از او بپرسید تعریف دقیق معناداری چیست، ممکن است گیر کند. گیر کردن در تعریف، لزوما به این معنا نیست که تحلیل را بلد نیست.»

### PC-SENT-002 — quote, then lower-abstraction paraphrase
- begins_with: compact claim or quotation
- pivot: به بیان ساده تر
- ending: a consequence the reader can use
- transferable_rule: Never leave a dense sentence without one plainer restatement. Change the level, not the synonyms.
- new: «حجم نمونه را نمی شود از روی حس انتخاب کرد. به بیان ساده تر: اگر ندانید اثر مورد انتظار چقدر است، عدد ۳۰۰ نفر یک آیین است، نه یک تصمیم.»

### PC-SENT-003 — question as genuine pivot
- begins_with: blocked path
- pivot: پس راه خروج چیست؟
- ending: a different kind of answer (not a longer version of the same)
- transferable_rule: A question earns its place only if the next sentence is a different type of move.
- new: «اگر فقط بگوییم پژوهش کیفی است، داور هنوز نمی داند داده از کجا آمده. پس چه باید نوشت؟ منبع داده، منطق نمونه، فن تحلیل، و ابزار.»

### PC-SENT-004 — analogy, then explicit return
- begins_with: ordinary scene
- middle: mapping
- ending: return marker + the concept
- transferable_rule: Analogies must come home. Do not leave the reader in the story.
- new: «تعمیر ساعت را با خواندن دفترچه گارانتی یاد نمی گیرند. باید بازش کرد. مرور ادبیات هم همین است: فهرست کردن عنوان ها کافی نیست؛ باید دید هر منبع دقیقا کدام ادعا را نگه می دارد.»

### PC-SENT-005 — not X but Y
- begins_with: rejected picture
- pivot: نه / بلکه
- ending: the replacement in one clause
- transferable_rule: Distinction beats decoration.
- new: «بیان مسئله، موضوع پژوهش نیست. موضوع می گوید درباره چیست؛ مسئله می گوید کجا گیر کرده ایم.»

### PC-SENT-006 — numbered concrete errors
- begins_with: فرض کنیم
- middle: two short cases
- ending: both fail for the same reason
- transferable_rule: Two mismatched examples teach a criterion better than one abstract rule.
- new: «فرض کنیم یکی فقط ده پرسشنامه پر کرده و دیگری چهارصد تا، اما هیچ کدام جامعه را تعریف نکرده اند. در هر دو حالت تعمیم بی معناست. عدد، جای تعریف جامعه را نمی گیرد.»

### PC-SENT-007 — self-correction / stronger formulation
- begins_with: weaker claim
- pivot: یا قوی تر / دقیق تر بگویم
- ending: scoped claim
- transferable_rule: Let the sentence upgrade itself. This is human reasoning, not indecision.
- new: «نرم افزار تحلیل را انجام نمی دهد. دقیق تر بگویم: نرم افزار محاسبه را اجرا می کند؛ انتخاب آزمون و خواندن معنا بر عهده پژوهشگر است.»

### PC-SENT-008 — colloquial punch after a formal run
- begins_with: careful distinction
- ending: short spoken-like line
- register: PROFESSIONAL_EXPLANATORY with one drop
- transferable_rule: One warm line is enough. Do not stay in chat.
- new: «آلفای کرونباخ پایایی را می سنجد، نه روایی را. این دو را اگر یکی بگیرید، کل فصل روش به هم می ریزد. همین.»

### PC-SENT-009 — agentless process, then named decision
- begins_with: what was done (passive/impersonal)
- ending: who must decide
- REGISTER: academic-readable / research-guide
- new: «داده ها وارد SPSS شد و آزمون t مستقل اجرا گردید. اینکه این آزمون اصلا مناسب این طرح هست یا نه، هنوز یک تصمیم است، نه یک خروجی.»

### PC-SENT-010 — first person as epistemic status
- begins_with: به نظرم / برداشت من این است
- ending: what would change the view
- transferable_rule: First person marks interpretation. It is not a personality feature.
- new: «به نظرم برای این طرح، مصاحبه نیمه ساختاریافته کافی است. اگر میدان پژوهش بسته باشد و دسترسی تکرار نشود، باید طرح را عوض کرد، نه اینکه همان ابزار را زور کرد.»

### PC-SENT-011 — contrastive اما as the thought-engine
- architecture: claim → اما → hidden assumption → restated claim
- new: «خیلی ها فکر می کنند هر چه منابع بیشتر، فصل دوم قوی تر. اما انباشتن منبع بدون پرسش، مرور نیست. مرور یعنی نشان دادن نزاع، نه ویترین.»

### PC-SENT-012 — everyday verb instead of bureaucratic noun pile
- repair: مبادرت به انجام تحلیل → تحلیل شد / تحلیل می کنیم
- new: «برای سنجش رابطه، رگرسیون خطی اجرا شد.»

### PC-SENT-013 — scope before predicate (Persian order)
- architecture: condition + known info + new info + verb
- new: «با توجه به توزیع غیرنرمال نمره ها، به جای آزمون t از آزمون یو من ویتنی استفاده شد.»

### PC-SENT-014 — parenthetical gloss on first mention
- new: «تحلیل عاملی اکتشافی (EFA) را وقتی به کار می بریم که هنوز نمی دانیم گویه ها روی چه عامل هایی می نشینند.»

### PC-SENT-015 — hedge a threshold, do not hide it
- new: «معمولا اگر ضریب آلفا از ۰/۷ بالاتر باشد، پایایی را قابل قبول می دانند. این یک قاعده تجربی است، نه قانون طبیعت.»

### PC-SENT-016 — reader situation, then precise term
- COMMON with Telegram student language (slice D)
- new: «داور گفته ایراد نگارشی دارد. یعنی ویرایش زبانی و ارجاع، نه لزوما ایراد در مدل آماری.»

### PC-SENT-017 — short sentence after a long one (brake)
- new: «اگر پیش فرض های آزمون برقرار نباشد، نتیجه پارامتریک گمراه کننده است. همین یک جمله باید جلوتر از جدول بیاید.»

### PC-SENT-018 — concession then limit
- new: «درست است که حجم نمونه بزرگ قدرت آزمون را بالا می برد. این به آن معنا نیست که طرح ضعیف با عدد جبران می شود.»

### PC-SENT-019 — list inside prose, then the point of the list
- new: «دستور می دهیم، گزارش می کنیم، سوال می پرسیم، اندازه می گیریم. زبان فقط نام گذاری اشیاء نیست؛ پژوهش هم فقط جمع کردن داده نیست.»

### PC-SENT-020 — interrupt the false method-question
- PC-STRONG
- new: «نپرسید روش تحلیل مضمون چیست تا یک دستورالعمل مستقل به دست آورید. ببینید با این متن ها عملا چه کار می کنید: خواندن، کد زدن، برگشتن، نام گذاشتن.»

### PC-SENT-021 — image that misleads, then what to do instead
- new: «تصویر گمراه کننده این است که نرم افزار از داده حقیقت را استخراج می کند. کار ما این است که آن تصویر را کنار بگذاریم و بپرسیم این آزمون برای این سوال چه می تواند بگوید.»

### PC-SENT-022 — two voices in one paragraph without clash
- setup colloquial, distinction formal
- new: «دانشجو می گوید داده هام جور درنمیاد. اگر منظور ناهمگونی واریانس است، اول آزمون لوین را گزارش کنید؛ اگر منظور داده پرت است، مسیر دیگری است.»

### PC-SENT-023 — close with a usable criterion, not a slogan
- new: «آزمون را وقتی عوض کنید که پیش فرض ها و سطح سنجش عوض شده باشند، نه وقتی از نتیجه خوشتان نیامده.»

### PC-SENT-024 — historical or named thinker, then the local use
- do not dump biography
- new: «کوهن از سنجش ناپذیری پارادایم ها حرف می زند. در فصل پیشینه، این یعنی نمی شود دو سنت نظری را فقط با یک جدول مقایسه کرد و برنده اعلام کرد.»

### PC-SENT-025 — question immediately answered
- new: «چرا همه پرسشنامه ها آلفای بالا نمی خواهند؟ چون مقیاس کوتاه، یا سازه ناهمگن، آلفا را پایین می آورد بدون اینکه ابزار لزوما بد باشد.»

### PC-SENT-026 — meta-comment about the argument (sparing)
- new: «تا اینجا فقط گفتم چه چیزی روایی نیست. حالا باید بگویم در این پژوهش روایی چطور بررسی شد.»

### PC-SENT-027 — scale shift
- new: «این مشکل فقط در یک گویه نیست. اگر سه گویه مجاور همین رفتار را دارند، مسئله طراحی خرده مقیاس است.»

### PC-SENT-028 — refuse a guarantee
- COMMON with practitioner slice F
- new: «هیچ مشاوری نمی تواند پذیرش مقاله را تضمین کند. می توان کیفیت استدلال، انسجام روش، و پاسخ به داوری را بالا برد.»

### PC-SENT-029 — ordinary conditional, not چنانچه
- new: «اگر داده ترتیبی است، میانگین را به عنوان آماره مرکزی گزارش نکنید.»

### PC-SENT-030 — final short line that does not summarise the article
- new: «کار تمام است وقتی سوال پژوهش با این داده قابل پاسخ است. نه وقتی فایل SPSS ذخیره شده.»

## 3. Fifteen paragraph architectures

Do not copy source paragraphs. Use the sequence.

### PC-PARA-001 — lived action → false theory-demand → punch
```
ordinary practice
↓
someone asks for a formula
↓
the formula-makers multiply
↓
the practitioner keeps working
↓
short spoken close
```
Suitable: INTELLECTUAL_CONVERSATIONAL, BLOG_LONGFORM, RESEARCH_GUIDE openings.
Caution: do not reuse carpentry / millipede / toolbox scenes. Invent a new ordinary scene.

### PC-PARA-002 — common belief → اما → problem → example → sharper claim
Suitable: all explanatory registers.
Caution: اما once per paragraph, not once per sentence.

### PC-PARA-003 — question → intuitive answer → distinction → precise answer
Suitable: guides, FAQ, educational posts.
Caution: if the precise answer = the intuitive answer, the question was fake.

### PC-PARA-004 — abstract → concrete → abstract (return with better terms)
Suitable: methodology explanation.
Caution: the return must add a term or a limit, not repeat the first sentence.

### PC-PARA-005 — quote/claim → paraphrase → consequence for the reader
Suitable: ACADEMIC_READABLE, commentary.
Caution: a quotation without the third move is a dump.

### PC-PARA-006 — two cases → shared failure → criterion
Suitable: teaching errors, "N اشتباه رایج".

### PC-PARA-007 — 1 / 2 / 3 staged distinction
```
what is already there
↓
what hides it
↓
what the work actually does
```
PC-STRONG. Suitable: conceptual explanation.
Caution: do not turn every topic into a mystic triad. Only when the thought has three jobs.

### PC-PARA-008 — objection → "وکیل مدافع شیطان" → reply → stronger reply
PC-STRONG as a move; the phrase itself is AUTHOR_SPECIFIC — do not copy the label.
Suitable: argumentative essays.
Rewrite the label: «یک اعتراض طبیعی این است که...»

### PC-PARA-009 — cultural object → personal reading → conceptual hinge
REGISTER: BLOG_LONGFORM / INTELLECTUAL_CONVERSATIONAL.
AUTHOR_SPECIFIC if it becomes a signature (series recap + Hobbes, etc.). Steal only the hinge, not the objects.

### PC-PARA-010 — process steps in prose, not a bureaucratic list
```
ابتدا ... سپس ... در نهایت
```
COMMON in slice F tutorials.
Suitable: RESEARCH_GUIDE, how-to.
Caution: web pages may then use a real numbered list; Telegram emoji numbers should become HTML lists.

### PC-PARA-011 — pitfall flag at the start
`توجه کنید که` / `یک اشتباه رایج این است که`
COMMON in F.
Do not bury the warning in the third clause.

### PC-PARA-012 — student wording → expert reframe
COMMON in D and G.
Do not mock the informal phrasing.

### PC-PARA-013 — limitation → what still holds → what to do next
REGISTER: ACADEMIC_READABLE, empirical papers.
Formulaic academic close is fine in theses; on the web, make it a decision.

### PC-PARA-014 — definition in one sentence, then use
Do not open a web page by defining a word the reader searched.
Academic artefacts may define terms; they still should not stall.

### PC-PARA-015 — repair of a picture, not replacement by a new theory
PC-STRONG.
```
false picture
↓
why the picture is tempting
↓
what we already knew how to do
↓
the picture is set aside, not swapped for a rival system
```
Use in conceptual writing. Do not import Wittgensteinian vocabulary into SPSS copy.

## 6. Thirty before / after examples

## 7. Anti-AI / anti-translationese repairs

Do not optimise for a detector. Repair reasoning and register.

| Symptom | Diagnosis | Repair |
|---|---|---|
| در دنیای امروز / در عصر حاضر | empty opener; absent in Iranian academic abstracts and in PC original explainers | delete; start with the job or the distinction |
| در این مقاله قصد داریم | announcement | delete |
| symmetric noun triplets | inflation (آماس) | keep one accurate noun |
| قدرتمند / جامع / یکپارچه / هوشمند | circulating tool-boilerplate | name the function |
| می باشد / می گردد / می نماید | officialese or dated textbook | است / شد / می کند |
| توسط + passive | English calque in **method** reporting | با / از سوی / drop agent — keep narrative توسط |
| مورد X قرار گرفت stacked | tolerated once in academic Persian; stacking is clutter | one simple passive |
| همچنین at the start of many sentences | filler cohesion (0.3% in PC originals) | new heading or delete |
| جهت سفارش / جهت نیل | bureaucratic; `از این جهت` is native | برای |
| آلفا as روایی | statistically wrong, even if fluent | پایایی / همسانی درونی |
| در ادامه ابتدا … سپس … | abstract meta-navigation | delete; start the first real move |
| every paragraph same width | structural regularity | vary because thoughts vary |
| no uncertainty anywhere | fake mastery | mark interpretation as interpretation |
| synonym rotation of پروپوزال / پایان نامه | SEO fear | fix the term and repeat |
| guarantee language | sales register | refuse |
| copied memorable analogy | imitation | invent a new ordinary scene |
| detector-evasion quirks | prohibited | write clearly |

## 9. Human tell that is actually a quality signal

From original PC explainers, corroborated by good independent Persian:

- uneven sentence length with a purpose
- a question that forces a distinction
- an example that is locally ordinary
- a reformulation at a different altitude
- an admitted limit
- a short line after a long one
- a register drop that serves comprehension, then a return
- verbs that do work

These are not quirks to inject. They appear when someone is actually thinking on the page.
